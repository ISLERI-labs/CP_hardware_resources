# ⚠️ DEVELOPMENT DRAFT — NOT YET HARDWARE VALIDATED
CP_1.0_D1 is the initial public architectural draft of the ISLERI CP communication protocol. The specification is currently undergoing hardware implementation and validation as part of CerePhyte 4.2 development.
Physical-layer parameters, hub implementation, timing limits, signal integrity, and performance characteristics remain subject to experimental validation.
